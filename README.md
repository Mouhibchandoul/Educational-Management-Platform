 🎓 Educational Management Platform

 📌 Project Overview

The Educational Management Platform is a web application developed to facilitate the management of educational activities and academic information.

The platform provides a structured environment for managing students, teachers, courses, and educational data through a centralized web interface.

The project was developed using the Symfony 6 framework and follows a structured web application architecture.



 🎯 Project Objectives

The main objectives of this project are:

* Digitize educational management processes
* Centralize academic information
* Facilitate the management of students and teachers
* Organize courses and educational activities
* Provide an intuitive web interface
* Improve data management and accessibility
* Develop a structured and maintainable web application

 🏗️ Architecture

The application follows the MVC (Model-View-Controller) architecture provided by Symfony.

```text
                 User
                   │
                   ▼
            ┌───────────────┐
            │   Web Browser │
            └───────┬───────┘
                    │
                    ▼
            ┌───────────────┐
            │    Symfony    │
            │    Routing    │
            └───────┬───────┘
                    │
                    ▼
            ┌───────────────┐
            │  Controller   │
            └───────┬───────┘
                    │
             ┌──────┴──────┐
             ▼             ▼
       ┌───────────┐  ┌───────────┐
       │   Model   │  │   View    │
       │ / Entity  │  │  Twig UI  │
       └─────┬─────┘  └───────────┘
             │
             ▼
       ┌─────────────┐
       │    MySQL    │
       │   Database  │
       └─────────────┘
```



 ⚙️ Main Features

 👨‍🎓 Student Management

The platform provides functionality for managing student information.

Main operations include:

* Student registration
* Student information management
* Student data consultation
* Updating student information
* Removing student records



 👨‍🏫 Teacher Management

The application allows educational staff information to be managed through a centralized interface.

Features include:

* Teacher registration
* Teacher information management
* Teacher data consultation
* Updating teacher information



 📚 Course Management

The platform provides tools for organizing educational courses.

Users can manage:

* Courses
* Course information
* Educational subjects
* Course assignments



 📊 Academic Data Management

The application centralizes educational information in a relational database.

This allows the system to:

* Store academic information
* Retrieve records efficiently
* Update information
* Maintain relationships between entities



 🗄️ Database

The project uses MySQL as its relational database.

The database is designed to organize the different entities of the educational system and their relationships.

Example structure:


Students
   │
   ├── Student Information
   │
   └── Academic Information

Teachers
   │
   └── Teacher Information

Courses
   │
   ├── Course Information
   │
   └── Assigned Teachers
